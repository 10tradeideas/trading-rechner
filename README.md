# TradingFreaks Renditerechner

Interaktiver Renditerechner für den Einsatz in Video Sales Letters und Videocalls.

## Live-Demo

→ [rechner.tradingfreaks.com](https://rechner.tradingfreaks.com) *(Link nach Deployment einfügen)*

## Struktur

```
Trading Renditerechner/
├── index.html         ← Die komplette Landing Page (HTML + CSS + JS)
├── assets/
│   └── tradingfreaks-logo.png
└── README.md
```

## Features

- 4 interaktive Regler: Startkapital, monatliche Einzahlung, monatliche Rendite, Zeitraum
- Live-Berechnung mit Zinseszins-Formel
- Live-Chart der Kapitalentwicklung (Chart.js)
- KPIs: Endkapital, Gesamtgewinn, geschätztes passives Monatseinkommen
- Vollständiges TradingFreaks-Branding (Neon-Grün auf Schwarz, Outfit-Font)
- Mobile-optimiert

## Lokal testen

Einfach `index.html` im Browser öffnen. Keine Build-Tools, keine Dependencies.

## Deployment

Der Rechner ist eine reine statische Seite — deploybar überall:
- GitHub Pages (kostenlos, direkt aus diesem Repo)
- Netlify (kostenlos, Drag & Drop)
- Cloudflare Pages (kostenlos)
- Eigener Webspace (einfach Dateien hochladen)

## Rechtlicher Hinweis

Die dargestellten Werte sind Modellrechnungen auf Basis der Nutzereingaben und stellen keine Gewinnprognose dar. Trading birgt Verlustrisiken.
